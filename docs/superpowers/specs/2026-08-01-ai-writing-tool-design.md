# AIライティングツール 設計ドキュメント

- 作成日: 2026-08-01
- ステータス: 承認済み

## 背景・目的

個人用のAIライティング支援ツール。日常的に発生する複数のライティング作業（ブログ執筆、メール返信、要約、SNS投稿文作成）を一つのアプリにまとめ、Gemini APIを使って生成する。

## スコープ

### v1に含める機能
1. ブログ記事執筆
2. メール返信文作成
3. 文章要約
4. SNS投稿文作成（Instagram向け、画像アップロード対応）

### v1に含めないもの
- データベース（永続化なし、生成結果はセッション内のみ）
- 認証・ログイン機能
- 複数ユーザー対応
- テンプレートエンジンによるプロンプト管理（プロンプトは各機能モジュール内に直接記述）

## 技術スタック
- Python
- Streamlit（ローカルWebアプリとして `streamlit run app.py` で起動）
- Gemini API（Google Gen AI SDK for Python）
- `.env`ファイルによるAPIキー管理（`.gitignore`で除外）

## アーキテクチャ

サイドバーで4機能を切り替えるシングルページのStreamlitアプリ。各機能は共通パターン（入力フォーム → 生成ボタン → 結果表示）に従う。

```
python-ai-app/
├── app.py                  # エントリーポイント、サイドバー、ルーティング
├── features/
│   ├── blog.py             # ブログ記事執筆
│   ├── email_reply.py      # メール返信文作成
│   ├── summarize.py        # 文章要約
│   └── sns_post.py         # SNS投稿文作成（画像対応）
├── gemini_client.py        # Gemini API呼び出しの共通ラッパー
├── .env                    # GEMINI_API_KEY (gitignore対象)
├── .env.example
├── requirements.txt
└── README.md
```

### ルーティング (`app.py`)
- サイドバーの `st.sidebar.radio` 等で機能を選択
- 選択された機能に応じて対応する `features/*.py` の `render()` 関数を呼び出す
- 起動時にAPIキーの有無をチェックし、未設定なら分かりやすいエラーメッセージを表示

### Gemini呼び出し (`gemini_client.py`)
- テキストのみのプロンプトを送る関数
- 画像＋テキストのプロンプトを送る関数（SNS投稿文作成用）
- 各 `features/*.py` はプロンプト文字列（および画像データ）を組み立ててこのラッパーを呼ぶだけ

## 各機能の入出力仕様

| 機能 | 入力 | 出力 |
|---|---|---|
| ブログ記事執筆 | テーマ/キーワード（必須）、文体・トーン選択（例: 丁寧語/カジュアル/専門的） | 記事全文 |
| メール返信文作成 | 受信メール本文（必須）、返信の方針（例: 日程を断る、感謝しつつ保留） | 返信文 |
| 文章要約 | 本文テキスト（必須） | 要約文 |
| SNS投稿文作成 | 画像アップロード（必須）、任意のメモテキスト（伝えたいポイントなど） | Instagram投稿文（キャプション） |

各機能ページの共通UXパターン:
1. 入力フォームを表示
2. 「生成」ボタン押下でGemini APIを呼び出し（`st.spinner`でローディング表示）
3. 結果を `st.code` で表示（コピーボタン付き）
4. 生成結果は `st.session_state` に保持し、他の操作でUIが再実行されても消えないようにする

## エラーハンドリング

- **APIキー未設定**: アプリ起動時にチェックし、サイドバーに`.env`設定を促すメッセージを表示。生成ボタンは無効化する。
- **入力未入力で生成ボタン押下**: `st.warning` でその場で指摘し、API呼び出しは行わない。
- **API呼び出し失敗**（レート制限・ネットワークエラー等）: `try/except` で捕捉し `st.error` にメッセージを表示。アプリはクラッシュさせない。

## テスト方針

個人用のUI駆動ツールのため、Streamlit UI自体の自動テストは行わない。プロンプト組み立て関数（API呼び出しを含まない純粋関数）のみ `pytest` で軽くユニットテストする。動作確認は `streamlit run app.py` での手動確認を基本とする。
